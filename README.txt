DRIVEN v0.9.0（2026-10-31）
==========================

■ 配置・更新
ZIPの中身を、現在のDRIVENと同じGitHub Pages公開フォルダへ配置してください。
index.html / workspace.js / workspace.css / recorder.js / sw.js /
manifest.webmanifest / iconsフォルダを一緒に更新します。
新しいリポジトリは不要です。公開操作はこちらでは行っていません。
公開後、右上のVer.ボタンで更新します。記録・測位中の更新は止めています。
HTTPSで一度オンライン起動し、次に機内モードでの起動を実機確認してください。
保存記録は従来と同じURL・ブラウザー領域で引き継がれます。別URLへの移動や
ブラウザーデータ消去で記録が見えなくなるため、先にバックアップしてください。

■ 4タブ
クルマ：GPX/JSON読込、複数ログの重ね表示、記録名タップで1件表示、
        速度グラフ、区間編集、名前変更・削除、GPX/CSV/JSON出力、印刷。
列車：クルマと同じ機能。車用と列車用の保存領域は分離しています。
測位：「現在地を見る」「地点を記録」「軌跡を記録」を選択します。
管理・説明：全体バックアップ・追加復元、欠測の秒数設定、地図の説明、使い方。

■ 現在地を見る
「現在地を取得（1回）」で、緯度・経度・accuracy・時刻・速度を表示します。
現在地マーカーを表示して地図を移動します。走行ログには追加しません。

■ 地点を記録
地点名・キロ程（例3k580m）・メモを入力→10/30/60秒から測定時間を選択
→測位開始→停止または時間到達→結果を保存。JSON/CSV出力も可能です。
代表緯度経度は各座標の中央値。accuracy中央値は代表座標の誤差保証ではありません。
元の全測位点と各accuracy・日時、測定点数、測定時間、入力情報を保持します。
GPSから取得できる点数は端末次第で、指定時間でも1点しか得られない場合があります。
地点の意味の現地確認と、座標精度の確定は別です。

■ 軌跡を記録
記録の種別（クルマ/列車）・記録名を指定→記録開始→一時停止→再開→記録終了。
保存先は指定した種別です。対応するクルマ/列車タブで確認できます。
地図の現在地、追従ON/OFF、速度、accuracy、経過時間、GPS概算距離を確認できます。
経過時間は開始から終了までの経過で、一時停止時間も含みます。
一時停止中は位置監視を停止し、再開時に新しい区間を開始します。
取得エラー後・非表示/前面復帰後も、停止前後を線でつなぎません。

「測位中は画面を消灯しない」をONにするとScreen Wake Lockを要求します。
非対応・拒否・OSによる解除がある場合は状況を表示します。
画面OFF・バックグラウンド・OSによる終了時の連続GPS取得は保証しません。
必要なら外部GPS Logger等で記録したGPXを読み込む運用を続けてください。

■ 欠測・区間の扱い
明示的なtrkseg区切り、breakBefore、一時停止、取得エラー、画面非表示後を分断。
外部ログも、点間の時刻が設定時間（標準30秒、15/30/60/120秒から変更）を
超えた箇所、時刻が逆転した箇所は、表示・印刷・距離集計・GPX出力で分断します。
原本の測位点を書き換えたり、欠測を補間して測位点を生成したりしません。
短いトンネル、時刻のないGPX、記録されていない取得エラーを完全に自動判定する
機能ではありません。欠測と思われる区間は元データと照合してください。
GPS概算距離は区切りをまたぐ距離を含めず、既存仕様に従い2km以上の点間距離も
集計から除きます。正式なキロ程や実距離を保証する値ではありません。

■ 区間編集
一覧の記録名をタップして1件表示→軌跡の区間編集→区間選択→地図上の開始/終了
を順にタップ、または1始まりの点番号で指定します。選択範囲は紫色です。
「この区間だけ別保存」「この区間を除外して別保存」で別の記録を作成します。
元記録を残し、元記録ID、元表示名、選択点番号、処理日時を加工記録に保持します。
区間除外後を接続しません。GPXはtrksegを分割、CSVにはbreak_before列を付けます。

■ 名前と原本
読み込み後の記録に表示名と原ファイル名を別々に保持します。
改名前の外部ファイルを変更・削除する操作はありません。
旧版の記録で保持されていない原ファイル名を推測復元しません。
書き出し名：日付_種別_記録名.gpx/csv/json
加工後は「_区間抽出」「_区間除外」を付け、使用できない文字は安全な文字へ変換。
JSONにはsourceとprocessingも保持します。GPXの任意の独自拡張タグすべてを
再現するものではないため、外部GPS Logger等の原ファイルは別途保管してください。
元GPXに時刻がない場合、新しい時刻を推測補完しません。

■ 印刷
クルマ/列車タブの「印刷・PDF」で対象記録と「全区間/地図で選択した区間」を選びます。
基本はA4横、速度グラフが左、軌跡地図が右。日付・種別・時間・GPS概算距離を
上部に表示し、START/END、手書き用MEMO欄を付けます。
従来の上下配置・地図のみ・速度のみ、地図色調、経過時刻の目印も残しています。
地図背景を印刷する場合は通信と画像の読み込みが必要です。

■ バックアップと保存
管理タブから車・列車・基準点・未完了記録・画面消灯防止/欠測設定をJSON保存。
復元は既存記録を残して追加します。同一ID・内容の記録は重複追加しません。
ブラウザーのlocalStorage容量には限りがあります。保存できないときは出力して
端末外へ保管してください。軌跡記録には「保存を再試行」もあります。

■ 地図・PWA
背景はOpenStreetMapのオンライン画像です。ダウンロード地図機能はありません。
低彩度化は描画時のみ適用し、元タイルを加工・保存しません。
カラー/地図なしにも切り替えられます。PWA本体と保存データはオフライン利用できます。
オンライン地図を表示すると、地図提供元へタイルを取得する通信が発生します。

■ 確認範囲・制約
Chromiumのスマートフォン幅で、読み込み、元ファイル名保持、区間編集、GPX分割、
現在地1回取得とログ非追加、記録一時停止/再開、取得エラー/画面状態後の分断、
車/列車への保存分離、模擬位置3点の地点記録、CSV出力、Wake Lockの要求と解放、
バックアップ復元、オフライン再起動を試験しました。
A4横の選択区間印刷はPDF出力で1ページに収まることを確認しました。
実機のGPS精度・消灯中の動作・OSのWake Lock解除・実プリンター・外部地図の到達性
は未確認です。速度グラフ上のドラッグによる範囲選択は今回未実装です。
自動車・列車の運転操作中に端末を操作しないでください。
測量・運転保安用途の確定座標を提供するものではありません。
