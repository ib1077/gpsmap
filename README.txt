DRIVEN v0.8.0 PWA（一式）
===========================

■ 入っているもの
index.html                DRIVEN 本体
workspace.js              4タブ・区間編集・基準点・全体管理
workspace.css             追加画面のスタイル
manifest.webmanifest       ホーム画面インストール設定
sw.js                      オフライン起動と更新用
icons/                     ホーム画面アイコン（PNG 192 / 512 / maskable）
README.txt                 この説明

■ GitHub Pages で使用
1. ZIPを展開し、上記のファイル・iconsフォルダを同じ階層に配置する。
2. 既存リポジトリなら対象リポジトリの公開フォルダにコピーする。
   ほかのPWAと同じ公開フォルダに index.html を上書きしないよう注意。
3. GitHub Desktopでcommit→pushし、GitHub PagesのHTTPS URLを開く。
4. Android版Chromeで「ホーム画面に追加」または「アプリをインストール」。
5. 初回は通信が必要。ページ読み込み後しばらくしてからオフラインで再起動を確認。

■ 画面と更新
上部はクルマ／列車／測位／管理・説明の4タブ。
クルマ・列車では地図→読込・一覧→区間編集→記録・出力・印刷。
右上の Ver.0.8.0 ボタンで更新確認・再起動。
GPS記録中・基準点測位中は、更新とタブ切替を禁止。
更新後のJavaScript・キャッシュ反映には公開先へのpushが先に必要。

■ オフラインについて
アプリ本体はService Workerでキャッシュし、オフラインで起動できます。
保存済み記録と読み込んだ軌跡は端末内に保持されます。
OpenStreetMapの背景地図は通信が必要です（オフラインでの地図タイル保存は行いません）。
画面の縮尺や中心位置によってはオフライン時に背景が表示されません。
GPSの位置取得と記録は端末環境・権限・アプリの前面動作に依存します。
OSがアプリを終了・バックグラウンド停止した場合の連続記録は保証しません。

■ データ保存について
車用と列車用は別のlocalStorageキーに保存し、混ざりません。
ただしfile://で開いたHTMLとGitHub PagesのURLは保存先が異なります。
旧版で記録が見えない場合は、旧版からGPX/JSONを書き出して新版へ読み込んでください。
重要な記録は定期的にGPX/JSON形式で端末外にもバックアップしてください。

■ 使用上の注意
GPS記録を始める前に位置情報を許可してください。GitHub PagesのHTTPSが必要です。
自動車・列車の運転操作中に端末を操作しないでください。
このアプリは走行記録を整理する目的の試作であり、安全・運転保安用途ではありません。

■ 補足
ローカルで開く場合も workspace.js / workspace.css を同じ場所に置いてください。PWA・測位には原則HTTPSが必要です。
DRIVEN v0.7 の画面・既存GPS記録・表示/印刷機能をベースにしています。

■ v0.8.0 改修内容（2026-10-31）
・4タブ：クルマ／列車／測位／管理・説明。
・クルマと列車：従来の記録開始・停止、現在地、複数ログ、重ね表示、GPX/JSON読込、GPX/CSV/JSON出力、印刷を維持。
・記録名をタップすると1件表示。そのタブの「軌跡の区間編集」で開始・終了を地図上でタップ、または1始まりの点番号を入力。
・「この区間だけ別保存」「この区間を除外して別保存」は元記録を残し、加工名と元記録ID・選択点番号（内部0始まり）を保存。原GPXファイル自体には書き込みません。
・区間除外後はbreakBeforeを保持し、画面・印刷・距離集計で接続せず、GPXはtrksegを分割。CSVにもbreak_beforeを追加。
・測位：地点名／キロ程／メモ→10/30/60秒測位→停止→保存またはJSON。代表緯度経度は各座標の中央値。元の全測位点・accuracy・時刻をJSONに保存。
・accuracy中央値は代表座標の精度保証ではありません。画面OFF・バックグラウンド記録は保証しません。
・全体バックアップと追加復元を管理タブに配置。既存の車・列車保存キーを維持。
・背景は描画時のみ低彩度化。カラー／地図なしにも切替可。地図画像を変更せず、地図ダウンロード機能は追加していません。
・速度グラフからの範囲選択、高度な地図連動、基準点GPX出力は今回未実装。基準点はJSONで保存・出力します。
・配布時はworkspace.js / workspace.cssを含む全ファイルを同じ場所へ配置してください。
・元GPXの独自拡張タグ全部を保持する設計ではありません。原ファイルは手元に保管してください。

■ 動作確認範囲
Chromiumのスマートフォン幅で、JSON読込、地図タップ選択、点番号指定、切出し、区間除外、原記録保持、GPX出力と再読込（区間分割・accuracy）、印刷プレビュー、車／列車の保存分離、模擬位置情報3点による中央値・全点保存、全体バックアップと別ブラウザー領域への復元、オフライン再起動を確認しました。JavaScript実行エラーは検出されませんでした。
実機のGPS精度、画面OFF時の挙動、プリンター出力、オンライン背景タイルの到達性はこの環境では未確認です。
