DRIVEN v0.10.0（2026-11-01）
===========================

■ 更新
ZIPの中身を、今のDRIVENと同じGitHub Pages公開フォルダへ配置してください。
index.html / workspace.js / recorder.js / compact.js /
workspace.css / compact.css / sw.js / manifest.webmanifest / icons/ を一緒に更新。
新規リポジトリ作成・GitHubへの公開操作は行っていません。
公開後は設定のVer.0.10.0ボタンで更新できます。記録・地点採取中の更新は止めます。
先に旧版で全体バックアップを取り、同じURL・ブラウザーで更新してください。
ブラウザーの保存データを消すと記録が失われるので、データ消去はしないでください。

■ HOME
［現在地・測位］［GPX編集］と小さな設定入口だけです。
HOMEではGPSを開始せず、画面の自動消灯も妨げません。
従来の4タブは通常画面から廃止しました。

■ 現在地・測位
入ると自動的に連続GPS取得（watchPosition / enableHighAccuracy:true）を開始。
GPSの更新ごとに現在地、速度、accuracy、地図の追従位置を更新します。
記録開始前の測位点は走行記録に保存しません。
地図を手で動かすと追従を解除。「現在地へ」で現在地へ戻り追従を再開します。
マーカーは取得した座標そのものです。予測位置や補間点は生成しません。
背景地図とGPSを別Canvasに描き、同一視点では背景を描き直しません。
連続した描画要求はrequestAnimationFrameでまとめます。

■ 軌跡記録
［記録開始］→［一時停止］→［再開］→［記録終了］。
一時停止中・終了後も現在地の表示と追従は続きます。
終了すると端末内へ保存し、記録名・種類（クルマ／列車／徒歩／その他）を付けて
GPX保存もできます。終了画面を閉じても、保存済み記録はGPX編集の一覧から開けます。
記録名・種類はGPX編集のメニューから後で変更できます。
保存容量不足時は測位メニューの「書き出し」でGPX/JSONを保管してください。
必要なら明示確認後に現在の測位画面の記録を破棄できます。保存済み記録は残ります。
HOME・GPX編集へ移動するとき、記録中なら終了・保存の確認を行います。
移動後はGPS監視を停止します。未完了記録は自動保存・復元にも対応しています。

■ 区間の分断・精度悪化
一時停止、取得エラー、画面非表示／前面復帰後、明示的なtrkseg/breakBefore、
設定時間（標準30秒、15/30/60/120秒）を超える欠測で区間を分断します。
記録中にaccuracyが100mを超えた点も原値を保持し、lowAccuracyを付けて前後を分断。
低精度点を精度良好な点に置き換えることや、間を補間することはしません。
GPS概算距離は分断部を含まず、既存仕様どおり2km以上の点間距離も集計から除きます。
短い欠測・時刻なしGPX・取得エラーが記録されていない外部ログを完全に判別する
機能ではありません。正式な距離・キロ程・測量精度を保証する値ではありません。

■ 地点記録
測位画面の［地点］から、地点名・km/m（例0k000m）・メモ・15/30/60秒を指定。
［採取］→自動終了または［終了］→［保存］。JSON/CSV出力も可能です。
走行記録と地点記録は分離しています。同じ連続GPS監視から各点を収集します。
全取得点、緯度経度、日時、accuracy、測定時間・点数、入力情報を保持します。
代表座標は従来の中央値を維持し、単純平均も別項目として保存します。
点のばらつきが小さくても、絶対位置の正確さが確定したことにはなりません。
指定時間でも端末によって1点しか得られない場合があります。
設定の「保存した地点」からは、GPSを開始せず過去の地点を確認・出力できます。

■ 画面維持
測位画面では、記録前・一時停止中・記録終了後もScreen Wake Lockを自動要求します。
HOME・GPX編集では解除。画面復帰時に必要なら再取得します。
非対応や取得失敗時は短い通知のみで、定期的な操作要求や警告音はありません。
OS・ブラウザーが解除することがあり、画面OFF・バックグラウンドのGPS記録は保証
しません。長時間記録は従来どおり外部GPS LoggerのGPXも利用してください。

■ GPX編集
GPX/JSONを「読込」から追加。上部の記録名ボタンで保存記録を選びます。
車・列車・徒歩を同じ画面で扱い、種類は記録ごとの属性として保持します。
複数ログのチェック重ね表示、1件表示、速度グラフを維持しています。
［区間］→地図で開始点・終了点→［切り出し］または［除外］で別記録を作成。
選択範囲は紫。メニューから点番号での精密指定も可能です。
原記録・原ファイルは残し、加工記録に処理名、元記録ID、処理日時等を保持します。
区間除外後は線を接続しません。GPXのtrkseg、CSVのbreak_beforeで区切りを出力します。
［出力］でGPX/CSV/JSON、［印刷］で全区間または選択区間を印刷できます。
メニューに名前・種類の変更、削除、一覧、元ファイル名、設定をまとめています。

■ ファイル名・原本
新しい出力名は日付_種類_記録名.gpx/csv/json。
加工後は「_区間抽出」「_区間除外」を付け、使用不可文字は安全な文字に変換します。
例：20261101_列車_上郡-智頭_区間抽出.gpx
読み込んだ元ファイル名と表示名は別に保持します。元ファイル自体は変更しません。
旧版に原ファイル名が残っていない場合、推測では補完しません。
GPXの任意の独自拡張タグすべてを再現するものではないので、元ファイルも保管してください。
時刻のないGPXに日時を推測補完しません。

■ 印刷
基本はA4横、速度左／地図右。概要、START/END、手書きMEMO欄付き。
全区間・選択区間、上下配置、地図のみ、速度のみ、地図色調、時刻目印を維持。
背景地図を印刷する場合は、通信・画像読み込み完了が必要です。

■ 1画面と持ち手
通常のHOME・測位・GPX編集はスクロール不要の構成です。
設定や記録一覧など長いダイアログは内部をスクロールできます。
右端に「〕」が出たら、その28px幅の領域を上下になぞると内容だけをスクロールします。
この領域は地図のドラッグを受け付けません。内容が収まる場合は持ち手を表示しません。

■ 保存・バックアップ・旧データ
v0.9のクルマ／列車は、初回に共通記録へコピーします。元の保存領域は削除しません。
新しい共通保存先：DRIVEN_TRIPS_v10、未完了：DRIVEN_RECOVERY_v10。
地点の保存先：従来のDRIVEN_REFERENCE_POINTS_v1を維持。
旧未完了記録は設定からコピー復元できます。旧バックアップの読み込みも対応。
全体バックアップには新旧記録、地点、未完了記録、欠測等の設定を含めます。
旧領域は移行時の保管用です。その後の新しい編集・削除は共通記録側に反映されます。
localStorageには容量制限があります。重要なファイルは端末外にも保管してください。

■ 地図・オフライン
背景はオンラインのOpenStreetMap。表示時に低彩度化し、元タイルを変更しません。
地図ダウンロード機能はありません。PWA本体と保存済み軌跡はオフライン利用できます。
オンライン背景表示では地図提供元へタイル取得の通信が発生します。

■ 確認範囲
Chromiumのモバイル表示（412×915、360×640、375×667、640×360）で通常画面の
収まり、連続測位、追従解除/再開、記録前非保存、一時停止・終了後の現在地更新、
Wake Lock要求/解除、地点の全点・平均/中央値保存、欠測・低精度分断、GPX編集、
区間別保存、印刷、旧記録コピー移行、旧バックアップ復元、右端の模擬タッチ操作、
オフライン起動、実行エラーなしを確認しました。
同じ座標の更新では背景を再描画しないことも確認しています。
実機の位置精度、画面消灯やOSによるWake Lock解除、オンライン地図到達性、実際の
指での操作感、実プリンターは未確認です。速度グラフからの範囲ドラッグは未実装。
自動車・列車の運転操作中には端末を操作しないでください。
